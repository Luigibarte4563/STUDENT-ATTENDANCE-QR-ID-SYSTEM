# QR Attendance System

## Overview
The **QR Attendance System** is a complete platform for managing school attendance via QR codes. It supports **Admins, Teachers, and Students** with real-time tracking, analytics, and reporting.

**Access the live system here:** [QR Attendance System](https://luigibarte4563.github.io/STUDENT-ATTENDANCE-QR-ID-SYSTEM/)

---

## Admin Dashboard (Full Control)
Full management of students, teachers, attendance, sections, and system settings.

### Features
- **Dashboard Home:** Total Students, Teachers, Present/Absent/Late Today, Sections, Alerts, Quick Actions (Add Student/Teacher, Generate QR)
- **Live Attendance Monitor:** Real-time scans, filter by Section/Grade/Date, auto-refresh
- **Student Management:** Add/Edit/Delete, bulk CSV upload, assign section, generate/print QR, view attendance history
- **Teacher Management:** Add/Edit/Delete, assign sections, set permissions, reset password
- **Attendance Records:** Filter by date/grade/section/student, view Time In/Out, export CSV/Excel/PDF
- **Reports & Analytics:** Daily/Monthly charts, late reports, perfect attendance, frequent absentees, class comparison
- **QR Code Manager:** Generate/print individual or batch QR, refresh QR per semester
- **System Settings:** School year, check-in/out times, late thresholds, email notifications, logo & school details

---

## Teacher Dashboard
Manage assigned classes and monitor student attendance.

### Features
- **Home Overview:** Present/Absent/Late today per class, notifications
- **Scan Attendance:** Laptop/phone/tablet camera, check-in/out, status, manual updates, excused absences
- **My Classes:** Student list, attendance today, reprint QR, view profile & history
- **Class Reports:** Daily/monthly attendance, stats, export
- **Notifications:** Alerts for frequent absences, repeated late, missing 3+ days, forgotten IDs

---

## Student Dashboard
Track personal attendance and QR codes.

### Features
- **My QR Code:** View/download/print, request replacement
- **Attendance Summary:** Total present/absent/late, percentage, monthly calendar
- **Recent Activity:** Last check-in/out, daily status, teacher notes
- **Profile Section:** Name, ID, Section, Grade, QR link

---

## Core Features
- Real-time attendance via QR
- Multi-role dashboards: Admin, Teacher, Student
- Bulk management & CSV upload
- Reports & analytics
- Export attendance data (CSV, Excel, PDF)
- Secure Firebase authentication

---

## Tech Stack
- **Frontend:** HTML, Tailwind CSS, JavaScript  
- **Backend:** Firebase Realtime Database, Firebase Authentication  
- **QR Code:** Integrated via Firebase  
- **Charts/Reports:** JavaScript chart libraries  

---

## Usage
- **Admin:** Manage system, students, teachers, QR codes, reports  
- **Teacher:** Track assigned classes, scan QR, mark attendance  
- **Student:** View attendance history and QR code
